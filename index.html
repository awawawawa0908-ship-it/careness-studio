なぜCVR重視なのか？

フォロワーが増えても売上に繋がらなければ意味がありません。ケアネス北島の目標はLINE登録→体験予約→入会のファネルを回すこと。Instagramは「認知」ではなく「行動を促す」ツールです。

→
入会
CVR投稿の3大原則
1
冒頭1行でスクロールを止める
「え、自分のことだ」と思わせる一文。数字・疑問形・意外性のどれかを必ず入れる。
40代から筋肉は毎年1%減る あなたの疲れは姿勢が原因かも
2
具体的な数字・実績を入れる
「痩せました」より「3ヶ月で-5kg」。信頼度と行動意欲が大きく変わります。
3
必ずLINEへのCTAで終わる
「プロフのLINEから無料体験予約」を毎回最後に入れる。
投稿文の使い方
1
曜日に合わせてタイプを選ぶ
水曜=豆知識、木曜=会員の声、土曜=イベント。告知は月1〜2回。
2
CVRフレームを選ぶ
PASONA：悩み→解決の王道。BFAB：実績先出し。クイズ：保存率UP。
3
CVRチェックで確認
5項目チェックで100%を目指す。
4
画像タブに送る
テーマが自動引き継ぎされます。
画像生成の使い方
1
テーマを日本語で入力
AIが自動でプロンプト変換。APIキーなしでも画像生成は無料。
2
テンプレートを選ぶ
5種類のプロ品質テンプレートから選択。投稿用+サムネイルが同時生成。
3
文字化けしない仕組み
AIは背景のみ生成。日本語テキストはCanvasで後から正確に合成。
動画編集の使い方
1
動画をアップロード
複数選択で自動結合。不要なクリップは削除可能。
2
タイムラインでカット
左右のつまみをドラッグして使いたい区間を選択。
3
字幕を追加
時間とテキストを入力。3種類のスタイルから選択。
4
書き出し
WebM形式。Instagram対応。

export default {
  async fetch(request) {
    if (request.method === "OPTIONS") {
      return new Response(null, { headers: {
        "Access-Control-Allow-Origin": "*",
        "Access-Control-Allow-Methods": "POST, OPTIONS",
        "Access-Control-Allow-Headers": "Content-Type" }});
    }
    const { apiKey, ...body } = await request.json();
    const res = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: { "Content-Type": "application/json",
        "x-api-key": apiKey,
        "anthropic-version": "2023-06-01" },
      body: JSON.stringify(body)
    });
    const data = await res.json();
    return new Response(JSON.stringify(data), {
      headers: { "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*" }});
  }
};
