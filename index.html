📌 なぜCVR重視なのか？

フォロワーが増えても売上に繋がらなければ意味がありません。

Instagramは「認知」ではなく「行動を促す」ツールとして設計します。

CVR投稿の3大原則
1
冒頭1行でスクロールを止める
「え、自分のことだ」と思わせる一文が必須。
数字・疑問形・意外性のどれかを必ず入れる。
40代から筋肉は毎年1%減る あなたの疲れは姿勢が原因かも なぜ同じ運動でも差がでるの？
2
具体的な数字・実績を入れる
「痩せました」より「3ヶ月で-5kg」。
信頼度と行動意欲が大きく変わります。
体重・数値 期間 会員数・満足度
3
必ずLINEへのCTAで終わる
「プロフのLINEから無料体験予約」を毎回最後に入れる。
これがないと投稿がそこで完結してしまいます。
プロフリンクへ LINE登録 無料体験
投稿文タブの使い方
1
曜日に合わせてタイプを選ぶ
水曜=豆知識、木曜=会員の声、土曜=イベント。
告知は月1〜2回のキャンペーン告知に使います。
2
CVRフレームを選ぶ（豆知識のみ）
PASONA：問題提起→解決策の王道パターン。初回はこれ。
BFAB：数字や実績から入るパターン。実績投稿に◎。
クイズ：参加型で保存率が上がりやすい。
3
生成後にCVRチェックで確認
5項目のチェックリストが表示されます。
100%になるよう足りない要素を確認してください。
4
「この内容で画像を生成」ボタンを活用
投稿文のテーマが画像タブに自動引き継ぎされます。
投稿文→画像→サムネを一気に揃えられます。
ワンポイント：「再生成」を押すたびに違うパターンで生成されます。気に入るまで何度でも試してください。
画像生成タブの使い方
1
テーマを日本語で入力するだけ
AIが自動で英語のプロンプトに変換し、Pollinationsで背景を生成します。
APIキーがなくても画像生成は無料で使えます。
2
投稿用画像とサムネイルが同時に生成される
1080×1080の投稿画像と、横型16:9・縦型9:16のサムネを自動生成。
生成後にそれぞれダウンロードできます。
投稿用 1:1 サムネ 16:9 サムネ 9:16
3
文字化けしない仕組み
AIには「文字なしの背景画像のみ」を生成させます。
日本語テキストはCanvas（ブラウザ描画機能）で後から正確に重ねているので、文字化けが起きません。
ヒント：背景画像は毎回ランダムに変わります。同じテーマでも「再生成」を何度か押して、気に入る背景を選んでください。
動画編集タブの使い方
1
動画をアップロード（複数OK）
複数の動画を選んで追加できます。追加した順番に繋がります。
不要なクリップは✕で削除できます。
2
タイムラインでカット位置を調整
タイムラインの左右のつまみをドラッグして、使いたい区間を選びます。
「カット箇所を確認」で実際の動画で確認できます。
3
字幕を追加する
時間（例：0:05）と字幕テキストを入力して「追加」を押します。
スタイルは3種類から選べます。
0:00 オープニング 0:10 本題 0:25 LINE誘導
4
サムネイルを取得する
スライダーで好きなフレームを選んでサムネイルに。
「AIサムネを自動生成」でテーマに合った画像も作れます。
書き出し：WebM形式で保存されます。Instagramへのアップロードに対応しています。
TPPOとは？
T徹底的に Pパクって Pパクって Oオリジナル化する

今Instagramで実際に成果が出ているコンテンツの構成・フック・形式を参考にして、それをケアネス北島の強みと掛け合わせます。
コピーではなく「学習→昇華」です。
TPPOタブの使い方
1
ジャンルと形式を選んで「調査する」
AIがウェブ検索でリアルタイムのトレンドを調査します（APIキー必要）。
2
バズパターンを確認する
3種類のトレンドパターンが表示されます。
HOT=今バズっている、RISE=急上昇中、NEW=新しいトレンド。
3
「このパターンでTPPO化」を押す
バズパターンをベースにケアネス北島の強み（遺伝子解析・InBody・姿勢カルテ）を盛り込んだ投稿文を自動生成します。
投稿文生成・TPPO調査のみ必要です。
画像生成・動画編集は設定不要（無料）で使えます。
STEP A　Cloudflare Worker作成（無料）
1
下のURLでアカウント作成
https://dash.cloudflare.com/sign-up
2
左メニュー「Compute & AI」→「Workers & Pages」→「Create application」
「Start with Hello World!」→「Get started」→ 名前は「careness-proxy」→「Deploy」
3
「Edit code」でコードを全部削除して以下を貼り付け → 「Deploy」
export default {
  async fetch(request) {
    if (request.method === "OPTIONS") {
      return new Response(null, { headers: {
        "Access-Control-Allow-Origin": "*",
        "Access-Control-Allow-Methods": "POST, OPTIONS",
        "Access-Control-Allow-Headers": "Content-Type" }});
    }
    const { apiKey, ...body } = await request.json();
    const res = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: { "Content-Type": "application/json",
        "x-api-key": apiKey,
        "anthropic-version": "2023-06-01" },
      body: JSON.stringify(body)
    });
    const data = await res.json();
    return new Response(JSON.stringify(data), {
      headers: { "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*" }});
  }
};
4
表示されるURLをコピー
例：https://careness-proxy.あなたのID.workers.dev
